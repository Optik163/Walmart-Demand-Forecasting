# Walmart Supply Chain Demand Forecasting (Retail)

## Business Problem
Retailers must forecast demand accurately to reduce stockouts and excess inventory.
This project predicts weekly product demand to support inventory planning decisions.

## Data
Weekly retail sales data with holiday indicators.

## Tools
- Python (pandas, numpy, statsmodels)
- Power BI / Tableau
- Excel (validation)

## Methodology
1. Data cleaning and exploratory analysis
2. Baseline forecasting using Moving Average
3. Advanced forecasting using Holt-Winters and ARIMA
4. Model evaluation using MAPE
5. Final model selection based on accuracy and business relevance

## Results
Holt-Winters achieved the lowest forecast error and effectively captured seasonal demand patterns.

## Business Impact
- Enables proactive inventory planning
- Reduces stockouts during peak periods
- Supports data-driven supply chain decisions
